# FutFusion SBC 0.8.1

## Türkçe

- Koyu/açık tema seçimi eklendi; tercih tarayıcıda saklanır.
- Üst sekmeler **CLUB · SBC · GALLERY · EASYSBC · BUY/SELL** olarak ayrıldı.
- Gallery yalnız koleksiyon setlerini, EasySBC kadro içe aktarmayı, Buy/Sell ise kulübe giriş ve alış/satış takibini gösterir.
- **Adımları ayrı ayrı yönet** bölümü sürekli görünür.
- Dar ekranda sekme göstergesi taşması düzeltildi.
- README Türkçe ve ardından İngilizce olarak yenilendi; proje kaynakları ve lisans bildirimleri korundu.

### Kurulum

Release içindeki `futfusion-sbc-0.8.1.zip` dosyasını çıkar. Tarayıcının uzantılar sayfasından geliştirici moduyla paketlenmemiş klasörü yükle. Mevcut kurulumda aynı klasörü güncelle, uzantıyı ve EA Web App’i yenile.

### Doğrulama

199 Node testi; örnek verilerle gerçek panel, tema kaydı, beş sekmenin içerik ayrımı, 360px görünüm ve alış/satış akışı. Gerçek EA hesabında alış/satış uçtan uca denenmedi. SBC gönderimi manueldir.

## English

- Added persistent light/dark theme selection.
- Split navigation into **CLUB · SBC · GALLERY · EASYSBC · BUY/SELL**.
- Gallery contains collection sets, EasySBC handles squad imports, and Buy/Sell handles club entry and trading records.
- Individual workflow steps are permanently visible.
- Fixed tab indicator overflow on narrow screens.
- Rewrote the README in Turkish followed by English, preserving source credits and license notices.

### Installation

Extract `futfusion-sbc-0.8.1.zip` from this release. Enable developer mode on your browser’s extensions page and load the unpacked folder. For an existing installation, update the same folder, then reload the extension and EA Web App.

### Validation

199 Node tests; browser checks with synthetic data covering the real panel, saved theme, five separate tab contents, 360px layout, and trading workflow. Purchases and sales have not been tested end to end on a real EA account. SBC submission remains manual.
